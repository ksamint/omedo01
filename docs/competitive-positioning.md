# 差异化定位（对标结论）

## 象限

- **横轴**：单次活动工具 → 培训全周期管理  
- **纵轴**：偏工具/演示 → 偏游戏化体验  

## 对标产品分层

| 层级 | 代表 | 强项 | 弱项（相对本产品） |
|------|------|------|-------------------|
| 现场互动 | Slido、Mentimeter、Vevox、XTriv、RoomPulse | 低摩擦加入、大屏、企业集成 | 训前训后闭环弱；游戏化深度不一 |
| 游戏化测评 | Kahoot!、Quizmodeon、Quizizz Wayground | 竞赛感、排行榜、多玩法 | 与组织人才数据、培训项目弱绑定 |
| 全周期 LMS | 企学宝、TalentLMS、Docebo、金明日元类方案 | 训前训中训后、权限与报表 | 现场「一节班会」的极致轻量与氛围感常被弱化 |

## 本产品核心差异点（已确认）

1. **同一数据主线**：训前测评 → 现场互动与积分 → 训后测评与报告，参与者 ID 与行为可关联（含匿名到场后补绑）。  
2. **现场优先**：60 秒内开房间、扫码加入、讲师控台 + 观众大屏双端，对标 Slido 级体验。  
3. **游戏化引擎贯穿**：积分、连胜、个人/团队榜、成就徽章，与 `Score` / `Achievement` 数据模型一致，而非零散插件。  
4. **多租户与角色**：组织隔离 + RBAC，服务内训机构、企业大学、外部公开课等多买方形态。  

## 非目标（首期避免分散）

- 替代完整 LMS 的复杂课表、SCORM、薪酬绩效深度对接。  
- 重客户端 App：坚持 Web + 扫码。
