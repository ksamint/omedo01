# 角色与场景（优先顺序已确认）

## 角色

| 角色 | 首期优先级 | 说明 |
|------|------------|------|
| 培训师 / 讲师 | P0 | 创建 `LiveSession`、控场、发起活动、看大屏与导出 |
| 学员 / 参与者 | P0 | 扫码加入、匿名昵称、答题与积分 |
| 组织管理者（HR / L&D） | P1 | 租户内多项目报表、前后测对比 |
| 平台管理员 | P1 | 多租户运维、功能开关 |
| 团队队长 | P2 | 分队 PK、团队积分汇总 |

## 场景优先级

1. **企业内训（线下班）** — 入职、合规、技能集训：人数多、要强控场与数据留痕。  
2. **外部培训机构公开课** — 多期次、品牌化大屏、课后报告售卖价值高。  
3. **教育 / 高校大班** — 课堂互动 + 期末小测，需匿名与防作弊策略（后续迭代）。  
4. **会议 / 峰会** — Q&A、投票为主，游戏化为可选模块。  

## 设计原则

- **默认配置按「企业内训线下班」优化**；会议模式通过「活动模板」关闭游戏化即可。  
- **权限最小化**：学员仅见当前 `joinCode` 会话；跨会话数据由组织角色审批后可见。
